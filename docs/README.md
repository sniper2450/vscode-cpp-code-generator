## Описание плагина и его возможностей

**C++ Code Generator** — это интерактивное расширение для среды разработки Visual Studio Code, предназначенное для быстрой и удобной генерации базовых управляющих конструкций языка C++ (`if`, `for`, `while`). 

В отличие от стандартных статичных сниппетов, этот плагин работает как живой конструктор: он опрашивает пользователя через удобные диалоговые окна и на лету собирает готовый программный код.

### Основные возможности плагина:
* **Интерактивный пошаговый опрос**: Плагин последовательно собирает параметры (логические условия, имена счетчиков-переменных, диапазоны и шаги циклов) через всплывающие окна ввода прямо в интерфейсе VS Code.
* **Автоматическое извлечение переменных (Парсинг)**: Вы можете объявлять новые переменные прямо в поле ввода условия (например, написать `int a > 0 && int b == 5`). Плагин сам распознает типы данных (`int`, `double`, `float`, `bool`, `char`, `std::string`) и достанет их из строки.
* **Умный вынос объявлений наверх**: Все найденные в поле ввода переменные плагин автоматически вырезает из условия и аккуратно выносит отдельными строками строго *перед* создаваемым циклом или условием. Это защищает ваш код от синтаксических ошибок компилятора C++.
* **Автоматическая фильтрация дубликатов**: Если вы случайно объявите одну и ту же переменную дважды в разных окнах ввода (например, при указании начала и конца цикла `for`), плагин автоматически отфильтрует повторы и вынесет наверх только одно уникальное объявление.
* **Идеальные автоматические отступы**: Плагин умеет считывать уровень вложенности той строки, на которой стоит ваш курсор. При вставке он автоматически выравнивает выносимые переменные, ключевые слова, фигурные скобки и комментарий `// TODO` по одной ровной линии, сохраняя красивую табуляцию вашего кода даже внутри сложных вложенных конструкций.

## Инструкция по запуску и тестированию

1. Убедитесь, что у вас установлен **Node.js** и среда **VS Code**.
2. Склонируйте репозиторий и откройте папку проекта в VS Code.
3. Откройте терминал в папке проекта и выполните команду `npm install` для инициализации манифеста зависимостей.
4. Нажмите клавишу **`F5`** на клавиатуре — откроется новое окно VS Code в режиме отладки расширений (*Extension Development Host*).
5. В открывшемся окне создайте или откройте любой `.cpp` файл.
6. Поставьте курсор на пустую строку, где необходимо сгенерировать конструкцию (включая вложенные блоки).
7. Вызовите плагин любым удобным способом:
   * Нажмите комбинацию горячих клавиш **`Ctrl + Alt + Q`** (или `Cmd + Alt + Q` на macOS).
   * Либо откройте палитру команд через **`Ctrl + Shift + P`** и запустите команду `C++ Code Constructor: Open Generator`.
8. Пройдите пошаговый диалог ввода параметров и оцените результат автоматической вставки и генерации структурированного кода.
