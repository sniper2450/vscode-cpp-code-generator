## 1. Описание плагина и его возможностей

**C++ Code Generator** — это интерактивный плагин (расширение) для среды разработки Visual Studio Code, предназначенный для интеллектуальной автоматизации написания управляющих конструкций языка C++ (`if`, `for`, `while`). 

В отличие от статичных сниппетов, данный инструмент представляет собой интерактивный конструктор, который опрашивает пользователя и на лету генерирует синтаксически корректный код.

### Основные возможности:
* **Интерактивный пошаговый диалог**: Сбор параметров (условий, имён счётчиков, диапазонов циклов) через всплывающие окна ввода прямо внутри интерфейса редактора.
* **Интеллектуальный синтаксический анализ (Парсинг)**: Плагин умеет распознавать инлайновые объявления базовых типов данных (`int`, `double`, `float`, `bool`, `char`, `std::string`) прямо внутри вводимого пользователем условия.
* **Автоматическое вынесение локальных объявлений**: Все обнаруженные в поле ввода типы данных автоматически вырезаются из условия и выносятся отдельными строками перед управляющим блоком, защищая создаваемую конструкцию от синтаксических ошибок C++.
* **Автоматическое форматирование кода**: Сразу после генерации плагин принудительно вызывает встроенный инструмент выравнивания документа, благодаря чему фигурные скобки, отступы и комментарии встают строго по правилам кодстайла.

## 2. Техническое описание функций и логики

### Используемые структуры данных
Для реализации логики плагина используется структура данных **`Set` (Множество)**. Она выступает в роли глобального накопителя для обнаруженных переменных в рамках одного конвейера генерации. Это гарантирует уникальность выносимых объявлений и полностью исключает дублирование переменных, если пользователь случайно объявил одну и ту же переменную дважды в разных полях ввода (например, в полях начала и конца цикла `for`).

### Архитектура и методы:
* **`activate(context)`** — Главная функция активации расширения, регистрирующая команду `code-generator.openForm` в контексте IDE. Управляет асинхронным конвейером UI.
* **`parseInlineDeclarations(conditionText)`** — Вспомогательный алгоритм синтаксического анализа. С помощью регулярного выражения `/\b(int|double|float|bool|char|std::string)\s+([a-zA-Z_][a-zA-Z0-9_]*)/g` находит типы данных, пополняет коллекцию `Set` и возвращает очищенную строку условия, содержащую только имена переменных.
* **`deactivate()`** — Функция деактивации для корректной очистки системных ресурсов при закрытии плагина.

**Пример работы парсера:**
* *Ввод пользователя в поле ввода условия:* `int a > 5 && int b == 0`
* *Результат автоматической генерации в редакторе:*
```cpp
int a;
int b;
if (a > 5 && b == 0) {
    // TODO: Your code here
}
```

## 3. Инструкция по запуску и тестированию

1. Убедитесь, что у вас установлен **Node.js** и среда **VS Code**.
2. Склонируйте репозиторий и откройте папку проекта в VS Code.
3. Откройте терминал в папке проекта и выполните команду `npm install` для инициализации манифеста зависимостей.
4. Нажмите клавишу **`F5`** на клавиатуре — откроется новое окно VS Code в режиме отладки расширений (*Extension Development Host*).
5. В открывшемся окне создайте или откройте любой `.cpp` файл.
6. Поставьте курсор в пустую строку
7. Вызовите плагин любым удобным способом:
   * Нажмите комбинацию горячих клавиш **`Ctrl + Alt + Q`** (или `Cmd + Alt + Q` на macOS).
   * Либо откройте палитру команд через **`Ctrl + Shift + P`** и запустите команду `C++ Code Constructor: Open Generator`.
8. Пройдите пошаговый диалог ввода параметров и оцените результат автоматической вставки и форматирования кода.
