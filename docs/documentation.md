# C++ Code Generator for VS Code

## 1. Общее описание проекта
Данное решение представляет собой плагин (расширение) для среды разработки **Visual Studio Code**, предназначенный для автоматизации генерации стандартных управляющих конструкций языка C++ (`if`, `for`, `while`). 

Плагин позволяет интерактивно собирать параметры для создания условий и заголовков циклов, избавляя разработчика от рутинного написания шаблонного кода.

**Состав проекта:**
* `extension.js` — основной файл плагина, содержащий логику инициализации, перехвата команд API, создания форм, парсинга и текстовых подстановок.
* `package.json` — манифест расширения, где зарегистрирована команда `code-generator.openForm` и системные триггеры активации.
* `docs/README.md` — файл пользовательской и технической документации.

**Математическая база и структуры данных:**
Для оптимизации разбора строк условий используется регулярное выражение синтаксического анализа и структура данных `Set` (Множество), гарантирующая уникальность генерируемых объявлений локальных переменных при их вынесении наружу из тела условий или параметров.

## 2. Техническое описание функций

#### Функция `activate(context)`
Главная функция активации расширения. Регистрирует команду `code-generator.openForm` внутри контекста расширения. Запускает асинхронный конвейер опроса пользователя через интерактивные компоненты UI, выполняет вставку сгенерированного кода и принудительно вызывает встроенную команду форматирования всего документа `editor.action.formatDocument`.

#### Функция `deactivate()`
Функция деактивации расширения. Автоматически вызывается средой VS Code для завершения работы плагина и очистки занятых ресурсов. В текущей реализации является пустой, так как управление жизненным циклом зарегистрированных команд делегировано системному механизму `context.subscriptions`.

#### Функция `parseInlineDeclarations(conditionText)`
Вспомогательный парсер текста. Принимает сырую строку (условие или параметр цикла), находит типы данных C++ с помощью регулярного выражения `/\b(int|double|float|bool|char|std::string)\s+([a-zA-Z_][a-zA-Z0-9_]*)/g`. 

Парсер заносит уникальные объявления локальных переменных в коллекцию `Set` для предотвращения дублирования и возвращает строку условия, полностью очищенную от ключевых слов типов данных (оставляя только чистые имена переменных).

**Пример обработки инлайнового условия:**
* **Ввод пользователя в поле:** `int a > 5 && int b == 0`
* **Результат автоматической генерации:**
```cpp
int a;
int b;
if (a > 5 && b == 0) {
    // TODO: Your code here
}
```
